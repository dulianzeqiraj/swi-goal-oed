=== 1. Noise model of the candidates (all values in relative salinity, sea water = 1)
Gamma_n(theta) = sigma^2 I + a^2 B B' + s_m^2 C_ell, (C_ell)_ij = exp(-|x_i - x_j| / ell), theta = (a, ell)
  sigma = 0.020   independent sensor noise (2% of sea-water salinity, as in example_network)
  a in [0.010, 0.030]   common error of each data-logger hub (logger drift / shared calibration between
                    recalibrations: 1-3% of sea-water salinity, 0.5-1.5 times the sensor noise)
  B   12 x 4 hub loadings: hub h = column h of candidates (hub 1: sensors 1-3 at x = 0.5625 m, hub 2: 4-6 at
      x = 1.0625, hub 3: 7-9 at x = 1.4375, hub 4: 10-12 at x = 1.8125 m)
  s_m = 0.020 fixed   model error (structural error of the section model at the sensors, equal to sigma)
  ell in [0.10, 2.00] m   from one cell (nearly independent at the sensor spacing of 0.375-0.5 m) to the
                    length of the section (one common pattern)
  nominal theta0 = (a, ell) = (0.020, 0.4472 m), the middle of the box (geometric middle in ell)
Reference channels r1-r4 (candidates 13-16): one sealed channel per hub (a conductivity cell in a sealed
  standard on the logger): zero sensitivity to the aquifer (rows [G_S; 0]), reads the hub error c_h with
  noise sigma_r = 0.005; its noise is correlated with the sensors of its hub through a^2 B. Joint covariance
  Gamma_joint = blkdiag(sigma^2 I_12 + s_m^2 C_ell, sigma_r^2 I_4) + a^2 [B; I_4] [B; I_4]'
Budget: 3 salinity sensors (piezometers) and at most 1 reference channel (a sealed cell on an existing
  logger, a small fraction of the cost of a sensor); budgets of 3-6 sensors for the certificate.

=== 2. Objective function
For sensors S (rows G_S) and reference channels R (rows 0), T = S u R, data y_T = [G_S; 0] m + e_T,
e_T ~ N(0, Gamma_joint(theta)_TT); the goal-oriented expected information gain (eigOperator, exact):
  EIG_goal(S, R; theta) = -1/2 log(1 - r2),  r2 = z_T' (K_TT + Gamma_TT(theta))^-1 z_T / sigma_q^2,
  K = [G; 0] Gam [G; 0]', z = [G; 0] Gam h', sigma_q^2 = h Gam h' (h = goal row)
Robust objective (Wald max-min of ROED):  J(S, R) = min_{theta in Theta} EIG_goal(S, R; theta),
  Theta = [0.01, 0.03] x [0.10, 2.00] m;  design problem  max_{|S| = k, |R| <= 1} J(S, R).
Supply cell: I(1{s > limit}; y_T) = thresholdGoalEig(Sigma_theta, -s0, T, 0, 17, -limit) with
  Sigma_theta = [K + Gamma_joint(theta), -z_s; -z_s', sigma_s^2]: the correlated noise is placed in the
  covariance of the readings and NOISEVAR = 0. This is exact, because thresholdGoalEig uses the readings only
  through Sigma(design, design) + NOISEVAR I and Sigma(goal, design); so the threshold function applies.
  It depends on the design only through r2_s (explained fraction of the variance of the supply salinity) and is
  increasing in it (Gaussian channels of higher r2_s are Blackwell-better), so J_supply = phi_t(min_theta r2_s)
  and the robust design for the yes/no question is the robust design for the Gaussian supply-salinity goal.
Check: data-space formula against eigOperator on all 1100 configurations (3 sensors, 0/1 reference) at
  theta = (0.030, 0.4472): max difference 1.58e-14 nats (salt mass), 6.88e-15 nats (supply salinity)
Check: thresholdGoalEig with the noise folded into Sigma (NOISEVAR = 0), a = s_m = 0, against the original
  call of example_network on all 220 designs: max difference 9.44e-16 nats

=== 3. Worst case over the box (Proposition N3)
d Gamma_joint / da = 2a [B; I][B; I]' >= 0 and (K + Gamma)^-1 decreases in the Loewner order, so r2 and
  EIG_goal are non-increasing in a: the worst amplitude is the upper end a = 0.030. ell is searched on a grid of
  41 log-spaced values in [0.10, 2.00] m, refined by fminbnd around the grid minimum for reported designs.
Numerical check on the grid a = [0.01 0.015 0.02 0.025 0.03] x 41 values of ell, all 1100 configurations x 2 goals:
  largest increase of r2 with a: -4.58e-06 (non-positive = non-increasing); worst point at the upper end of a
  for 2200 of 2200 (configuration, goal) pairs; worst ell at the lower end for 308, at the upper end for 977,
  in the interior for 915: the worst correlation length depends on the design, as in ROED.

=== 5. Certified upper bound on the robust optimum (no enumeration of the designs)
Derivation. Let Theta_c = {a_hi} x {11 values of ell} (a subset of the search grid, a subset of Theta). For
  every design OPT_k(Theta) <= OPT_k(Theta_c) because a minimum over a smaller set is larger. EIG_goal =
  phi(r2) with phi increasing (phi(x) = -1/2 log(1 - x); phi_t for the yes/no question), so the robust
  problem is max_S min_theta r2 and any bound U on it gives phi(U). For a fixed reference set R0 and a
  scenario theta_j, relax the sensor weights w in the capped simplex Delta_k = {0 <= w <= 1, sum w = k}:
    r2_j(w) = z' P_j(w) (I + K P_j(w))^-1 z / sigma_q^2,  P_j(w) = (R_j + W (Gamma_j - R_j))^-1 W,
  the noise-inflation relaxation (Certified OED, eq. 36-38, Theorem 15 with a diagonal inflation, its
  Appendix A.6) with R_j = blkdiag(rho_j I_12, sigma_r^2 I_|R0|), rho_j = lambda_min(sigma^2 I + s_m^2 C_ellj),
  the inflation borrowed from the non-correctable part (Gamma_j >= Gamma_e,j >= R_j). It is exact at binary
  w (P_j(1_S) = E_S' Gamma_SS^-1 E_S) and concave (P_j operator concave, X -> h'(Gam^-1 + G'XG)^-1 h convex
  and non-increasing). Gradient: d r2_j / d w_i = rho_i ((N_j' \ v)_i)^2 / sigma_q^2, N_j = R_j + W(Gamma_j - R_j),
  v = (I + K P_j)^-1 z. Then for every w_bar in Delta_k and every lambda in the simplex of the scenarios
    max_S min_j r2(S; theta_j) <= max_{w in Delta_k} sum_j lambda_j r2_j(w)
                               <= sum_j lambda_j r2_j(w_bar) + gamma_FW(sum_j lambda_j grad r2_j(w_bar), w_bar),
  gamma_FW(g, w) = sum of the k largest g_i - g'w (Frank-Wolfe certificate, Theorem 8). lambda = e_j gives
  min_j (best-k bound at theta_j) (min over theta of an upper bound of the best k-subset); a mixed lambda (the
  soft-min weights at the relaxed max-min point) gives the max-min (dual) bound. Reference channels: the
  bound is the maximum over the 5 reference sets R0 (none, r1-r4). Two cruder valid bounds, for any R:
  the interference-free ceiling (N2: EIG(S u R; theta) <= EIG_e(S; theta), Gamma_e = sigma^2 I + s_m^2 C_ell,
  relaxed in the same way) and the full network (all 16 channels; more data never lose information).
  The certificate is the smallest of these bounds; the certified gap of a design is U - J(design).
