# Albanian originals (archived)

These are the original Albanian versions of the 26 literature reviews and the two PRAG-GO research notes.
The English versions, which are the current documents, are in `docs/literature/` (`Literature_review_*.docx`)
and `docs/research_notes/` (`Research_note_*.docx`). The English versions keep every number and equation of the
originals; a few small errors found during the translation were corrected only in the English versions
(for example, in Section 10.4 of the TMLE review, continuous time: the design with the drought index reaches an error of 0.050 with
2 000 wells, not with 1 000 as the original says).
